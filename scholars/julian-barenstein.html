Julián Barenstein

MEDIUM

Interpretation Summary Argues for a non-esoteric reading of De umbris idearum in which Hermeticism and Renaissance natural magic are not treated as determinative for understanding the text. Emphasizes the regulation of memory and the work's cognitive function instead. Represents the position that the magical interpretation of Bruno's memory art has been overextended.

Memory

Memoria regulata — regulated, disciplined memory as a cognitive achievement in its own right, not requiring an esoteric/magical frame to be intelligible.

Magic

Skeptical that Hermeticism/natural magic should be treated as determinative for interpreting De umbris.
